## 💻 Local Development

### Prerequisites
- Node.js 20+ (v22 recommended)
- npm or pnpm

### Getting Started

```bash
# Clone the repository
git clone https://github.com/am-afl/am-afl.github.io.git
cd am-afl.github.io

# Install dependencies
npm install

# Run the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the live result.

### Production Static Export

```bash
# Build and export static assets to /out
npm run build
```
